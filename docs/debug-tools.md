# 其他调试工具

断点调试之外的日常手段：串口打印、上位机看曲线、日志系统。它们不打断程序运行，是调试实时性代码（电机闭环、RTOS 多任务）的首选。

## 串口调试工具

- printf 重定向：通过 printf 用串口发送相关的信息，用串口调试助手等提供上位机
- 串口调试助手：SSCOM、XCOM 等任选，收发十六进制/字符串
- 蓝牙串口模块（HC-05 等，见"常用模块"章）接 UART 即可无线打印，车在跑、人在旁边看数据

## VOFA+

- [VOFA+](https://www.vofa.plus/) — 支持波形绘制的串口上位机，**调 PID 看曲线必备**，可自行 B 站搜索教程

## Segger RTT 日志系统

强烈建议在任何运行的程序上都引入一个日志系统，可以在调试器当中获得系统的实时运行信息。这里有很多方式：

* 用上述的串口打印，在程序运行的代码中插入 printf 打印一些关键的变量，利用 VOFA+ 等上位机观察

* 若使用 Ozone 调试，建议移植 SEGGER 公司的 RTT 日志，结合 Ozone 的 Terminal 窗口使用

  [工程调试利器：RTT（Real-Time Transfer）保姆级使用教程_rtt调试-CSDN博客](https://blog.csdn.net/qq_38364548/article/details/154431687)
