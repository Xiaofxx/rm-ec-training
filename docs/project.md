# 综合项目（小车）

前面所有章节的知识在这里汇成一件完整的作品。一辆小车会依次用上：C 语言、GPIO / PWM / 编码器、串口与蓝牙、PID 与电机控制，进阶还能练 RTOS 任务划分。完成它，就意味着你已具备独立开发的能力，这也是培训成果的最终检验。

## 项目选型

- 队内校内赛 / 培训赛赛题待补充。
- 可以参照全国大学生电子设计竞赛（电赛）的控制类小车题目，例如循迹小车、运动目标控制等题目要求明确、成果可验证。搜索相关的教程和模块也可以

## 建议的推进顺序

1. 点灯、串口打印环境跑通（对应"STM32 开发基础"章）
2. 遥控器 / 蓝牙指令接收，串口协议解析（"通信协议""常用模块"章）
3. 电机开环转动 → 编码器测速 → 速度环 / 位置环 PID（"电机控制"章）
4. 循迹 / 打点逻辑，用状态机组织模式切换（"数据结构与算法"章）
5. 整车联调与鲁棒性优化（"调试方法"章）
