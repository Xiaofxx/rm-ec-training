# 嵌入式第零课：安装 STM32CubeMX

1. 首先安装 Java 环境。运行以 `jre` 开头的文件并完成安装，安装路径不要有中文。

    ![运行 Java 安装程序](assets/cubemx/01.png)

2. 安装 Java 后，运行以 `Setup` 开头的文件并完成安装，安装路径不要有中文。

    ![运行 STM32CubeMX 安装程序](assets/cubemx/02.png)

3. 安装到快捷方式设置这一步时，直接保持默认选项即可。

    ![保持默认快捷方式设置](assets/cubemx/03.png)

4. Java 和 STM32CubeMX 的具体安装过程可参考 [STM32CubeMX 下载及安装教程_Brendon_Tan 的博客-CSDN 博客](https://blog.csdn.net/Brendon_Tan/article/details/107685563)的第三部分。

    ![参考教程的第三部分](assets/cubemx/04.png)
