# 数据结构与算法

数据结构与算法是编程能力的基本功，需要长期积累。对电控来说这些内容不只是应试：FreeRTOS 的任务链表、串口接收的环形缓冲区、模式切换的状态机，都是本章内容的直接应用。

## 刷题路线

- [代码随想录](https://programmercarl.com/) — 按专题组织的免费刷题路线（数组 → 链表 → 栈队列 → 二叉树 → 动态规划…），讲解详细，中文社区口碑最好的一套。
- [LeetCode 中国](https://leetcode.cn/) — 刷题主平台，题目分级清晰，支持 C 语言作答。
- [OI Wiki](https://oi-wiki.org/) — 数据结构与算法的查阅手册，讲义式组织。

## 视频

- [B 站搜索：王道数据结构](https://search.bilibili.com/all?keyword=王道+数据结构) — 讲解系统完整，适合从头过一遍知识体系。

## 嵌入式方向的应用

- 链表 — FreeRTOS 内核的任务调度大量使用；建议用 C 手写实现一次单向/双向链表。
- 队列 / 环形缓冲区 — 串口不定长数据接收的标准做法（配合"通信协议""调试方法"章）。
- 状态机 — 遥控器模式切换、发射机构流程控制的惯用写法，综合项目会实际用到。

## 学习建议

- 学习宜早、贵在坚持：每周固定题量，重质不重量，做完写总结。
- 用 C 语言手写一遍链表与队列（创建、插入、删除、遍历），队内考核可能要求现场手写。
- 队内考核通常围绕 C 语言基础与简单算法题展开（具体安排见"待补充"）。
