# 电子扫盲篇

本篇旨在帮助那些缺少相关基础的同学，若您有相关基础可不必费时间在此处，继续向后学习即可。

很多同学在上大学前缺少接触电脑的时间，对电脑的基本使用技巧及常识有部分欠缺。希望各位通过阅读本文档能够对电脑相关知识及技巧形成一个大致的认知，在之后还需同学自己实操来体验、熟悉相关功能。
