# 常用模块

在学习单片机及其外设的同时，肯定会结合具体的模块进行开发，这里给出一些常见模块，建议大家购买并适配驱动到你的工程上面，这同样也有益于你对于一些通信协议，外设的理解和使用。

## IMU（惯性测量单元）

- MPU6050 — 入门最常用的 6 轴 IMU，I2C 接口，资料极多，价格便宜0飘也严重。。
- BMI088 — RM 开发板自带的高性能 IMU；姿态解算可参考官方和一些战队开源代码。

## 直流电机驱动模块

- TB6612 / L298N — 有刷直流电机的经典驱动方案。配合编码器测速，是"电机控制"章的练习对象。

## 舵机

- SG90 / MG995 等 — PWM 脉宽直接控制角度，与定时器 PWM 衔接

## OLED 屏

- 0.96 寸 SSD1306（I2C 接口）— 最常用的调试显示件，开源驱动库很多。

## 蓝牙串口模块

- HC-05 等透传模块 — 接在 UART 上即可无线打印与发指令

## 找例程的通用方法

首先可以先向购买模块的商家要资料，或者B站搜索具体模块的对应教程。读懂再移植到你的代码工程上，不要整包照抄，有的商家例程写的是真的一眼难尽。。。
