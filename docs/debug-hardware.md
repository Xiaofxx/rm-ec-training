# 硬件调试

> 这或许是最折磨也是最耗时的一个阶段。。。

代码查不出问题时，问题往往在硬件上。硬件调试的三板斧——万用表、电烙铁、示波器——是电控成员的必修技能，实验室的仪器可按队内流程借用（见文末待补充）。

## 万用表测通断

排查的第一步永远是**量电**：电源有没有电、线路有没有断、短路在哪里。

- 常见用途：测通断（蜂鸣档）、测电压（确认 3.3V/5V/24V 供电正常）、测电阻
- 典型场景：板子不上电 → 先量电源输入有没有电压；外设不工作 → 量它的供电引脚；怀疑断线 → 蜂鸣档顺着线量通断
- 入门视频：[B 站搜索：万用表使用入门](https://search.bilibili.com/all?keyword=万用表使用入门)

## 线材焊接

电控日常离不开焊接：杜邦线、排针、XT60 电源线、电机线，焊接质量直接决定机器人赛场上会不会"突然断电"。

- 常见任务：焊排针（开发板/模块）、焊电源线（大电流线材尤其要焊牢）、飞线修补
- 入门视频：[B 站搜索：电烙铁焊接入门](https://search.bilibili.com/all?keyword=电烙铁焊接入门)
- 提醒：注意烙铁温度与松香的使用；大电流线材（电机/电源）务必热缩管绝缘，避免短路

## 示波器看波形

示波器能把"看不见的电信号"变成屏幕上的曲线，是硬件问题的终极排查手段。

- 常见用途：看 PWM 波形与占空比、看电平跳变、看电源纹波、看通信信号
- **逻辑分析仪**（示波器的近亲）— 抓 UART / I2C / SPI / CAN 波形，对照协议时序图定位通信问题（与"通信协议"章配合），入门视频：[B 站搜索：逻辑分析仪入门](https://search.bilibili.com/all?keyword=逻辑分析仪+入门)
- 入门视频：[B 站搜索：示波器使用教程](https://search.bilibili.com/all?keyword=示波器使用教程)

> 补充：市面上有 DAP-Link 类的**无线调试器**，方便远程/车体调试，不过目前看来依旧不如有线调试稳定。
