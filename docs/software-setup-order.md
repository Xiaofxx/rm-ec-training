# 软件作用与配置顺序

开始学习前，请先按照本页了解各个软件的用途和配置顺序，再进入对应的图文教程完成安装。

除 **CLion** 和 **Keil** 需要二选一作为主要的嵌入式开发环境外，**Dev-C++、Git、STM32CubeMX、J-Link 和 Ozone 都需要配置**。在 CLion 与 Keil 之间，**更推荐使用 CLion**，它也是队内项目开发的首选。

## 各个软件的作用

| 软件 | 作用 | 是否需要配置 |
| --- | --- | --- |
| [Dev-C++](install-devcpp.md) | 用于前期 C/C++ 语法学习和基础程序练习，自带编译器，安装后即可编写并运行程序。 | 需要 |
| [Git](install-git.md) | 用于记录代码修改、管理版本，以及下载和同步 GitHub、Gitee 或队内代码仓库中的工程。 | 需要 |
| [STM32CubeMX](install-cubemx.md) | 用于选择 STM32 芯片、配置时钟和外设，并生成初始化代码与工程。 | 需要 |
| [CLion](install-clion.md) | 用于编写、阅读、构建和管理嵌入式工程，具有现代化的代码编辑、跳转、重构、CMake 和 Git 集成功能。 | 与 Keil 二选一，推荐 |
| [Keil](install-keil.md) | 用于编写、编译、烧录和调试 STM32 工程，配置较直接，传统教程和旧工程较多。 | 与 CLion 二选一 |
| [J-Link](install-jlink-ozone.md) | 作为电脑与开发板之间的调试器，用于把程序下载到芯片并进行硬件调试。 | 需要 |
| [Ozone](install-jlink-ozone.md) | 配合 J-Link 进行程序调试、断点控制、变量观察和运行状态分析。 | 需要 |

## 推荐配置顺序

1. **安装 [Dev-C++](install-devcpp.md)**：先完成 C/C++ 基础学习环境的配置，并确认能够编译运行一个简单程序。
2. **安装并配置 [Git](install-git.md)**：尽早使用版本管理工具，方便后续获取、保存和同步工程。
3. **安装 [STM32CubeMX](install-cubemx.md)**：用于后续创建 STM32 工程和生成初始化代码。
4. **选择主要的嵌入式开发环境**：
    - 推荐安装 [CLion](install-clion.md)，用于队内项目开发。
    - 也可以安装 [Keil](install-keil.md)，用于学习传统 STM32 工程或打开已有 Keil 工程。
5. **安装 [J-Link](install-jlink-ozone.md)**：完成电脑、调试器与开发板之间的连接和程序下载环境配置。
6. **安装 [Ozone](install-jlink-ozone.md)**：配合 J-Link 完成独立调试环境的配置。

请按以上顺序配置。每一项涉及的前置组件、安装选项和详细操作，均已包含在对应的图文教程中，本页不再重复说明。

## CLion 与 Keil 的区别

CLion 和 Keil 都可以承担嵌入式代码开发与工程构建工作，选择其中一个作为主要开发环境即可。

| 对比项 | CLion | Keil |
| --- | --- | --- |
| 使用体验 | 界面和代码编辑功能更现代，代码跳转、重构和补全体验更好 | 界面较传统，但配置直观、相关教程较多 |
| 工程与工具链 | 适合 CMake 工程，便于维护较大项目 | 常用于传统 MDK 工程，兼容大量已有示例和旧工程 |
| Git 集成 | 集成功能完善，适合多人协作 | 通常需要配合外部 Git 工具使用 |
| 使用建议 | **推荐使用，是队内项目开发的首选** | 可用于学习传统开发流程或处理已有 Keil 工程 |

如果没有必须使用 Keil 工程的情况，建议直接选择 **CLion**。两者可以同时安装，但没有必要同时作为主要开发环境。
