# 电机控制

让电机"听话"是电控组的核心技术：底盘要稳、云台要准、发射要匀速，背后都是控制算法。这一章是电控组技术含量的集中体现，也是入队后参与项目的核心技能。

## 有刷直流电机（PWM + 驱动模块）

- [TB6612 教程（搜索）](https://www.bing.com/search?q=TB6612+STM32+PWM) — PWM 调速 + 方向控制的入门方案，配编码器可做测速闭环，是练习 PID 的最佳起点。

## PID 控制

- [B 站搜索：PID 控制](https://search.bilibili.com/all?keyword=PID控制+算法) — 优先看动画/仿真演示型视频，直观理解三个环节各自的作用。
- 位置式 / 增量式、积分限幅、串级 PID 等实现细节：[搜索入门博客](https://www.bing.com/search?q=位置式+增量式+PID+串级+详解)
- [野火文档中心](https://doc.embedfire.com) 也有 PID 与电机专题教程。

## 无刷直流电机（RoboMaster 体系）

- [RoboMaster 规则 / 资料中心](https://bbs.robomaster.com/wiki/20204847) — M3508 / M2006 与 C610/C620 电调、GM6020 的说明书：CAN 控制帧格式、反馈报文、电流映射都在里面。
- 控制链路：主控 → CAN（见"通信协议"章）→ 电调 → 电机。电调内部跑 FOC，主控侧只需要发送目标电流。
- [SimpleFOC](https://www.simplefoc.com/)（[中文文档](https://docs.simplefoc.com/)）— 开源 FOC 框架，想深入理解无刷驱动原理、自己搭磁编码闭环时推荐。

## 前馈控制

- [搜索：前馈控制 + PID](https://www.bing.com/search?q=前馈控制+PID+云台) — 在反馈之外按模型直接补偿（重力、摩擦等），云台控制中与串级 PID 配合使用，各战队开源代码有大量实践。

## 学习建议

路线建议：在有刷电机 + 编码器上调速度环 → 位置环 → 串级，再迁移到 RM 电调的电流环。调参顺序先 P 后 D 再 I，配合 VOFA+ 之类上位机看曲线（见"调试方法"章）。
