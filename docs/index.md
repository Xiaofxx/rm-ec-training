# 欢迎

这里是苍穹战队电控组培训资料的入口，面向准备加入战队电控组的新成员。本教程梳理一条从零基础到能独立完成项目的学习路线，并为每一站配好资料。

## 培训目标

- 掌握嵌入式开发的基本技能栈：C 语言 → STM32 → 通信协议 → RTOS → 电机控制
- 能独立完成一个小型机器人/小车项目（见"综合项目"章）
- 通过队内考核，正式加入电控组，进入项目组参与比赛开发

## 其他

本教程内容定位是**学习路线 + 资料导航**（不写知识点讲解，只给推荐教程、资料链接和学习建议），具体的知识点请自行学习。
