# 欢迎来到电控组培训教程

这里是电控组培训的统一入口，面向准备加入战队电控组的新成员。电控组负责机器人的"神经系统"——从主控程序、电机驱动到传感器采集与通信，机器人每一次流畅的运动背后都是电控的工作。本教程梳理一条从零基础到能独立完成项目的学习路线，并为每一站配好资料。

## 培训目标

- 掌握嵌入式开发的基本技能栈：C 语言 → STM32 → 通信协议 → RTOS → 电机控制
- 能独立完成一个小型机器人/小车项目（见"综合项目"章）
- 通过队内考核，正式加入电控组，进入项目组参与比赛开发

## 如何使用本教程

1. 每章开头是"为什么学"，中间是推荐资料（名称 + 链接 + 推荐语），结尾有学习建议和待补充清单。
2. 章节按推荐学习顺序排列，建议按顺序推进；已有基础的成员可跳跃选读。
3. 资料不在多，选定一种教程坚持学完比收藏十份更有用。
4. 各章结尾的"待补充"由队内持续填充，欢迎提改进意见。
