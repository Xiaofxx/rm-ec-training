# Git 与工程化

队内代码协作与开源项目参与全部围绕 Git 展开，掌握 Git 是参与战队开发的前提。目标不是背命令，而是能独立完成"改代码 → 提交 → 协作合并"的完整循环。

## 入门教程

- [廖雪峰 Git 教程](https://www.liaoxuefeng.com/wiki/896043488029600) — 最流行的中文入门教程，从安装到分支一路跟完即可上手。
- [Pro Git 中文版](https://git-scm.com/book/zh/v2) — Git 官方书籍，免费在线阅读，进阶查阅用。

## GitHub 使用

- [GitHub Docs（中文）](https://docs.github.com/zh) — 官方文档，仓库、Pull Request、Issues 等概念不清楚时来查。
- 协作基本流程：fork / 建分支 → 提交 → 发 Pull Request → 代码评审后合并。队内代码统一走 GitHub 托管。

## 工程化实践

- `.gitignore`：Keil / CubeIDE 工程要忽略编译产物，避免仓库膨胀（模板见待补充）。
- 提交信息：一条 commit 只做一件事，写清楚"改了什么、为什么改"。
- README：每个仓库写清功能、依赖、编译方法——这也是一个项目仓库的门面。
