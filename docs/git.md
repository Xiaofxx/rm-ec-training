# Git 与工程化

队内代码协作与开源项目参与全部围绕 Git 展开，掌握 Git 是参与战队开发的前提。目标不是背命令，而是能独立完成"改代码 → 提交 → 协作合并"的完整循环。

git可以说是任何一个软件工程师必备的技能，这部分不强制要求，但对于你来说**使用git版本管理代码必须是养成的良好习惯**

## GitHub 等平台使用

Github作为全球最大的开源社区，建议自行登录创建账号，建立个远程仓库试试，

同样的，还有Gitee（如果不能魔法上网登上Github，建议用这个国内的平台），Gitea等代码托管平台

## 建议

关于这部分使用，git的教程网上都有，但常常忽略的是你的代码规范和提交方式了，建议自行搜索并养成良好的提交规范，对于开发需要回退版本等场景有非常好的帮助

学会了git的使用方式，这里不仅建议你用来托管自己的代码，同时也去逛逛论坛，B站之类的，可以找到Github等网站上的优质开源项目，拉取下来学习相关的内容
