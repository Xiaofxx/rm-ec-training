# 调试方法

嵌入式调试能力直接决定开发效率：同一个问题，会调试的人十分钟定位，不会的人烧一下午板子。从"打印大法"到仪器测量，手段按成本递增。

## 串口打印

- printf 重定向：[搜索教程](https://www.bing.com/search?q=STM32+printf+重定向) — 最基础的调试手段；注意与"通信协议"章的串口收发共用外设时的冲突。
- 串口上位机：[VOFA+](https://www.vofa.plus/) — 支持波形绘制，调 PID 看曲线必备；正点原子 XCOM 等纯收发工具也可。

## 在线调试（断点）

- Keil / STM32CubeIDE 均支持断点、单步、观察变量、外设寄存器视图，配合 ST-Link / DAP-Link 通过 SWD 连接目标板。
- 注意：调试实时性代码（如电机闭环）时断点会破坏时序，此时优先用打印 / 波形。

## 仪器测量

- [B 站搜索：逻辑分析仪入门](https://search.bilibili.com/all?keyword=逻辑分析仪+入门) — 抓 UART / I2C / SPI / CAN 波形，对照协议时序图定位通信问题（与"通信协议"章配合）。
- 示波器 — 看 PWM 波形、电源纹波、驱动信号，队内仪器借用方式见待补充。

## 无线调试

- 蓝牙串口模块（见"常用模块"章）接 UART 即可无线打印，车在跑、人在旁边看数据。
- 进阶：搜索 "Segger RTT STM32" — 比 UART 更快、不占用串口外设的日志方案。
