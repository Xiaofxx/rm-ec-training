# RTOS（实时操作系统）

当任务多到 `while(1)` 主循环里塞满标志位轮询、时序难以维护时，就需要 RTOS。RoboMaster 官方例程与绝大多数战队代码都基于 FreeRTOS，看懂它是参与战队开发的前提。

## 裸机 vs RTOS

裸机（前后台）系统：主循环轮询 + 中断置标志，简单直接但任务一多就难维护。RTOS：功能拆成多个任务，由内核按优先级调度，任务间通过队列、信号量等机制通信。两者没有绝对优劣，但在多任务、强实时的机器人场景下，RTOS 的结构优势明显。

## 学习建议

- 先"会用"：任务创建与优先级、队列、信号量、软件定时器，在 STM32 工程里跑起来。
- 再"懂原理"：任务调度机制、临界区保护，这是读懂战队代码的基础。
- 结合工程练：把"通信协议"章的串口接收改造成"任务 + 队列"结构。
